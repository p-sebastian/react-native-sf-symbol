# Contributing

Public fork pull requests are proposals. Nontrivial changes require a linked issue; small documentation corrections
are exempt. Keep proposals narrowly scoped, test observable behavior when behavior changes, and update public
documentation when the package contract changes.

Use Bun for project commands:

```bash
bun install --frozen-lockfile
bun run typecheck
bun run test
bun run build
```

Repository-authored source files carry the copyright and SPDX headers used in this repository. Contributions are
offered under the MIT License without a separate CLA or DCO. Acceptance and timing are not guaranteed. External work
may be manually recreated on an owner-controlled branch before privileged validation or merge.
