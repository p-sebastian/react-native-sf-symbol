# Security Policy

Only the latest published version receives security consideration. Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/p-sebastian/react-native-sf-symbol/security/advisories/new),
not through a public issue.

Include the affected version, impact, a private reproduction, and a suggested remediation when known. Please
coordinate disclosure until a fix is available or another disclosure point is agreed. No acknowledgement or
resolution timeline and no bug bounty are promised.

Ordinary correctness problems belong in a reproducible public bug report.
